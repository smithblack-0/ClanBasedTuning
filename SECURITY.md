# Security policy

ClanBasedTuning is pre-release software and does not currently designate a stable production
version as security-supported.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting / **Report a vulnerability** interface for this
repository when it is available. Include the affected version or commit, impact, reproduction
information, and any suggested mitigation there.

Do not publish exploit details, credentials, private data, or a weaponized proof of concept in
a public issue. If GitHub private vulnerability reporting is unavailable, open only a minimal
public issue asking the maintainer to establish a private contact channel; omit sensitive
technical details until that channel exists.

There is no guaranteed response-time SLA while the project remains pre-release. Reports
should nevertheless be acknowledged and triaged before a release is represented as suitable
for production use.
