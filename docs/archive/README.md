# Documentation archive

This directory preserves completed or superseded project material that remains useful for audit or historical explanation.

Archived files are not active product, architecture, implementation, or acceptance authority. Current work must follow [`docs/README.md`](../README.md), the current source and tests, and the active documents linked there.

- `milestone_1/` preserves the completed framework-alignment research and its review record.
- `milestone_2/` preserves the completed or superseded evolutionary-controller gate and plan.
- `superseded/` is reserved for obsolete designs whose content is still worth retaining outside the active reader path.
