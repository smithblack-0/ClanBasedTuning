# Active plans

This directory contains accepted execution plans for the active milestone.

A plan is subordinate to the product roadmap, accepted project decisions, and the
active milestone gate. It may sequence concrete work inside that gate, but it may
not add acceptance criteria, act as a second gate, or choose implementation for a
later milestone.

Tentative alternatives, framework notes, and unresolved reasoning belong in
scratchwork until human review accepts a design or plan. Completed or superseded
plans should be removed or archived without leaving competing authority in the
active reader path.
