# Framework evidence

This directory contains active version-sensitive evidence about PyTorch, Lightning, and Ray behavior.

Use [`evidence_ledger.md`](evidence_ledger.md) when an architectural or implementation claim depends on upstream framework behavior. Evidence supports decisions and qualification; it does not assign work or define the public API.

The accepted Milestone 1 explanatory report, acceptance record, and review audit are preserved under [`../archive/milestone_1/`](../archive/milestone_1/). They are historical records rather than active implementation authority.

Current architecture is entered through [`../design/README.md`](../design/README.md). Current project state is in [`../../STATUS.md`](../../STATUS.md).
