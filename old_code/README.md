# Historical integration code

The repository previously contained proof-of-concept Ray Tune, Lightning, PyTorch DDP,
checkpoint, optimizer-application, factory, framework-contract, and end-to-end example
implementations. Those files were removed from the active tree before Milestone 3 was
restarted because they embodied unaccepted and sometimes conflicting architecture.

The code remains available through git history, including the repository state before
this cleanup and the closed or rejected integration pull requests. It is evidence, not
a supported module, implementation template, or source of architectural authority.

Later work may inspect a historical implementation to recover a focused framework fact
or test idea. It must not restore the old subsystem wholesale. Any reused behavior must
be re-earned against the current roadmap, accepted decisions, milestone gate, senior
engineering workflow, direct framework evidence, and focused tests.
